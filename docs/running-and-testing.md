# Running and testing Artinarey

This document covers the local developer workflow for the daemon and the M6 read-only desktop window.

## Prerequisites

- Node 26 and pnpm 10.34.9
- Rust 1.100 or newer
- Tauri 2 system dependencies
  - On Linux: WebKitGTK and GTK 3 development packages
  - A desktop display session; a headless container needs Xvfb or an equivalent display
- A registered project. Use the CLI to register one before expecting data in the window.

Check the Tauri environment from `apps/gui`:

```bash
cd apps/gui
pnpm exec tauri info
```

## Start the daemon

The window reads daemon snapshots over loopback. Start the daemon first, from the repository root:

```bash
pnpm install
node packages/cli/bin/artinarey daemon start
```

Check that it is running:

```bash
node packages/cli/bin/artinarey daemon status
```

Stop it when finished:

```bash
node packages/cli/bin/artinarey daemon stop
```

The daemon writes its token, port and operator capability file under the resolved config directory. With default XDG settings this is `~/.config/artinarey/`.

## Run the window in development mode

The Tauri config points at `http://localhost:5173`; it does not start Vite automatically. Use two terminals.

Terminal 1 — Vite dev server:

```bash
cd apps/gui
pnpm exec vite
```

Terminal 2 — Tauri window:

```bash
cd apps/gui
pnpm exec tauri dev
```

The webview alone is not useful: `invoke` requires the Tauri shell. If the daemon is not running, the window renders a typed `DAEMON_UNREACHABLE` error instead of an empty list.

## Build and run the native window

From the repository root:

```bash
pnpm run build:gui
cd apps/gui
pnpm exec tauri build
```

The release binary is:

```text
apps/gui/src-tauri/target/release/artinarey-gui
```

For a debug binary:

```bash
pnpm run build:gui
cargo build --manifest-path apps/gui/src-tauri/Cargo.toml
./apps/gui/src-tauri/target/debug/artinarey-gui
```

`apps/gui/dist/` is generated by `build:gui` and is ignored by git.

## Test gates

Run these from the repository root before committing:

```bash
pnpm run typecheck
pnpm test
pnpm run lint
pnpm build
pnpm run test:gui
pnpm run build:gui
cargo build --manifest-path apps/gui/src-tauri/Cargo.toml
```

`test:gui` runs the Rust proxy tests. `build:gui` builds only the frontend bundle; it does not build the native app.

Focused commands used while developing are also available:

```bash
node --import tsx --test packages/daemon/src/gui.test.ts apps/gui/src/gui.test.ts
node --import tsx --test packages/daemon/src/http.test.ts
node --import tsx --test packages/daemon/src/operator.test.ts
node --import tsx --test apps/gui/src/gui.test.ts
pnpm --filter artinarey-gui exec vite build
git diff --check
```

The final privacy check must report clean before publishing.
